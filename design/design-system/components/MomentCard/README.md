# MomentCard

A moment on the trail: photo, week, caption and hugs, slightly tilted like a postcard.

Alternate tilts down the trail (-1.5deg, 1deg). The photo is the hero; with no photo yet, show a soft-block slot with a happy character.

- Provide: `week`, `caption`, optional `note`, `src` + `alt`, `tint`, `character`, `hugs`, `tilt`, `peek` (a character over the corner for firsts), `href`.
