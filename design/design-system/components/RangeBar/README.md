# RangeBar

A milestone's typical window from birth to 18 months, with today's marker.

Ranges, not report cards. Keep the note line; the milestone detail screen adds "not yet is fine" and points to the baby clinic.

- Provide: `label`, `start` and `end` in months (on a canvas, `from` cannot take a `{{ }}` value, so always use `start`/`end`), optional `now` and `note`. Users can hide ranges in Privacy.
