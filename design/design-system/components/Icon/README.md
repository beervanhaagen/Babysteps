# Icon

Thirty-three hand-drawn interface icons on a 24px grid with a 2.2px round stroke.

Icons inherit `currentColor`. Use 24px in rows, 22px with a 2.6 stroke inside the active tab pill and on buttons, 20px for chevrons in `ink-muted`.

- Provide: `name`, optional `size`, `weight` (stroke width) and `title` when the icon stands alone.
- No emoji in the product.
