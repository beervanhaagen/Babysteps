# Segmented

Two or three ways to look at the same thing, like T1's "Tijdlijn" and "Raster". The chosen one is a sunshine sticker inside a pill with an ink edge; the others are plain.

Each option is at least 44px tall and has a label; an icon is optional. Only in the React Native package for now (`packages/ui`).

- Provide: `label` (spoken name of the group, e.g. "Weergave"), `options` (`value`, `label`, optional `icon`), `value`, `onChange`.
