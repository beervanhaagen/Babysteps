# TabBar

Four tabs, two either side of the blue +: Trail, Family, the +, Hugs (T6 Activity) and Me. The + has its own fixed slot in the middle, with two equally wide tabs on each side, so it stays exactly centred whatever the labels or text size. A small rose dot on Hugs means new hugs. The Book tab is out while the year book is in the backlog (owner, 20 October 2026).

The + is the only lifted control in the app: it always opens "What happened?". The current tab sits in a sunshine pill.

- Provide: `active` + `onChange`, `onAdd`; in React Native also `news` (tabs with a dot). Not shown on onboarding, sheets or celebration screens.
