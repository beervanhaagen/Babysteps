# TabBar

Three tabs and the blue + to add a moment: Trail, Family, the +, Me. The Book tab is out while the year book is in the backlog (owner, 20 October 2026); it comes back between Trail and the + when the book returns.

The + is the only lifted control in the app: it always opens "What happened?". The current tab sits in a sunshine pill.

- Provide: `active` + `onChange`, `onAdd`. Not shown on onboarding, sheets or celebration screens.
