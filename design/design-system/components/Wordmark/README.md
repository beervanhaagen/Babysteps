# Wordmark

The teddysteps logotype: Bagel Fat One in rose over a cornflower offset, with a twinkling star.

Always lowercase, always one word. Use `size` 54 or larger on paper; in a coloured header use `tone="header"` (paper face, ink offset, no star) at 26px.

- Provide: `size`, optional `tone` ("paper" default or "header"), `twinkle={false}` to drop the star.
- Never recolour, outline or set it in another font.
