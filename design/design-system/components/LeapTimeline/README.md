# LeapTimeline

The first year as one line, with each developmental leap (sprongetje) as a dot: done in pistachio, the next one big in sunshine, and today as the tangerine marker.

This is the visual "what's next" that keeps parents coming back. Leaps follow the commonly cited leap weeks (around 5, 8, 12, 17, 26, 36, 44, 53, 62 and 73), **counted from the due date, not the birth date**. Always present them as a rough guide: every baby has their own pace, and it is not medical advice. Use our own names for leaps, never the names from a published book.

- Provide: `now` (week, from due date), optional `end` (default 52), `leaps` (weeks), `nowLabel`, `nextLabel`, `weekWord`, `axis` + `axisLabels`, and an accessible `label`.
- On a canvas pass numbers and arrays through `{{ }}` holes.
