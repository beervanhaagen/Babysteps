# Button

Sticker buttons: Bagel labels, a 2.5px ink edge and a hard drop they press into.

**Every action is bluebird.** One `primary` per screen. `dark` (ink with a rose drop) is for the book and paid things, `paper` for the second choice, `sunshine` inside callouts, `danger` (plum) only to confirm a delete.

- Provide: `children` (what happens, in a few words), optional `variant`, `size` ("lg" 58px at the bottom of a screen; "md" 48px inside cards and rows), `block`, `icon`, `href`.
- Bottom actions sit in a 24px-padded footer, full width (`block`).
