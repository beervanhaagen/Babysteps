# Doodle

Crayon doodles that glue the gang to the content: stars, hearts, sparkles, suns, zigzags and squiggles.

Scatter two to five in the gaps around headers, book pages and celebrations. They twinkle unless `twinkle={false}`.

- Provide: `name`, `size`, optional `color` (a token name) and `delay`.
- Default inks: star, twinkle and sun in sunshine, heart in tomato, sparkle in cornflower, zigzag in forest, squiggle in rose.
- Never behind body text, never more than one of each kind in a small area.
