# NextUp

A card on the trail that tells parents what is coming: the next leap or a typical first, when it roughly happens, what they might notice, and what is worth capturing.

Tone: reassuring and practical, never a warning or a deadline. Lead with what they might notice, end with a moment to capture, so the card turns into a new moment on the trail.

- Provide: `title`, `when`, optional `eyebrow`, `items` (2 or 3 short lines), `children`, `character`, `tone` (a soft-block token; default white).
